# 使い方

OfficeAssistとデスクトップ版Excelを起動し、Excelでセル範囲を選択してから、エクスプローラーやSSCaptureの通知など、画像ファイルをドラッグできるアプリから画像をシートへ左ドラッグします。表示される画面で挿入先・サイズ・形式を選んで「挿入」を押します。「キャンセル」ではシートを変更しません。保存はExcelで行ってください。

- 挿入先はドロップ位置または選択範囲の左上です。
- サイズは原寸大または選択範囲に縦横比を保って収める方法です。複数の図を範囲に収める場合は範囲を縦に分割します。
- 埋め込みは画像をブックに保存します。リンクされた図はExplorerからの画像で選べ、元ファイルへの参照を保存します。外部アプリからの画像では短命な一時ファイルへの参照切れを避けるため、リンクは選べません。
- IMAGE関数式では画像ごとに直接取得できるHTTPSの画像URLを指定します。OneDriveやSharePointの同期パスを自動変換・公開しません。認証が必要なURLやリダイレクト先の画像はExcelで表示できない場合があります。選択範囲への複数挿入は左から右、上から下の順です。既存値や結合セルには上書きしません。

起動すると画面を表示せず通知領域に常駐します。アイコンを右クリックし、「Excelへの画像ドロップ」のチェックを外すと一時停止します。設定は起動中だけ有効で、次回起動はONです。メニューの「開く」で状態画面を表示でき、×で閉じても常駐します。完全に終了するには通知領域メニューの「終了」を使います。

## 制限とエラー

- PNG/JPEG/BMP/GIF/TIFFの実ファイルを最大50件受け付けます。GIFは静止画像として挿入します。
- 1ファイル50MiB、画像100メガピクセルまでです。非画像やフォルダーを混ぜた操作は対象外です。
- リボン・数式バー・シートタブ・グラフ専用シートへのドロップは対象外です。
- 編集中セル、ダイアログ表示中、保護ビュー、読み取り専用ブック、保護されたシートでは挿入しません。編集を終えてから再操作してください。
- Excelの外で始めた左ドラッグが対象です。画像の実ファイルをFileDrop形式で渡し、コピーを許可するアプリから受信できます。Excel内のセル選択・図の移動を画像挿入へ置き換えません。右ドラッグ、Web上の画像、ZIP内の仮想ファイルは対象外です。
- ドロップを受理する前にOfficeAssist側で画像を確保し、挿入方法の選択中も保持します。SSCaptureが元の一時PNGを整理しても埋め込みに使えます。受信コピーは挿入完了・キャンセル・失敗時に削除し、元ファイルは変更しません。リンクされた図を使う場合は、先に通常の画像ファイルとして保存し、Explorerから渡してください。
- ExcelとOfficeAssistは同じユーザーの通常権限で実行します。管理者起動やWeb版Excelは対象外です。
- Excelの自動操作により標準の「元に戻す」履歴が失われる場合があります。挿入画像を除くにはExcel上で選択して削除してください。
- 成功結果はOfficeAssist画面で確認できます。エラーはダイアログと画面に表示されます。一括挿入の途中で失敗した場合は、今回追加した画像・数式の取り消しを試みます。取り消せなかった場合はその旨を表示します。

Windowsへの自動起動登録はこの版では提供しません。`--startup`による無表示起動には対応しています。
