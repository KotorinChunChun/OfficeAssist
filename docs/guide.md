# 使い方

OfficeAssistとデスクトップ版Excelを起動し、Excelでセル範囲を選びます。画像ファイルをドラッグできるアプリ（エクスプローラーやSSCaptureの通知など）から、マウスの左ボタンで画像をシートへドラッグします。初期状態ではダイアログを表示せず、保存済みの設定（「選択範囲」「埋め込み」）で挿入します。修飾キー（初期値はShift）を押しながらドロップすると、ダイアログの表示・省略が通常時と逆になります。設定画面で「挿入」を押すと、設定を既定値として保存します。「キャンセル」では設定とシートを変更しません。ブックはExcelで保存してください。

- 挿入先はドロップ位置（原寸大）、選択位置の左上（原寸大）、または選択範囲に縦横比を保って収める方法から選びます。
- 選択範囲にはExcelの範囲順に画像を１枚ずつ割り当て、挿入済みの範囲を選択から外します。画像が範囲数より多い場合は、残りすべてを最後の範囲に入れて警告します。最後の範囲に複数の図を収める場合は縦に分割し、原寸大では縦に並べます。全範囲を使い切った場合、Excelは選択を空にできないため、選択外の隣接セルへ移します。ドロップ位置では選択範囲は使用しません。
- 「埋め込み」は画像をブックに保存します。「リンクされた図」はExplorerから渡した画像で選べ、元ファイルへの参照を保存します。外部アプリから渡した画像では、一時ファイルがすぐになくなって参照できなくなるのを避けるため、リンクは選べません。
- IMAGE関数式では画像ごとに直接取得できるHTTPSの画像URLを指定します。URLは保存しないため、この形式は省略設定にかかわらず毎回入力画面を表示します。OneDriveやSharePointの同期パスを自動変換・公開しません。認証が必要なURLやリダイレクト先の画像はExcelで表示できない場合があります。最後の範囲に複数のIMAGE関数を挿入する場合は左から右、上から下の順に空セルを使います。セルが足りない場合や既存値・結合セルがある場合は上書きせず、挿入しません。

起動すると画面を表示せず通知領域に常駐します。アイコンを右クリックし、「Excelへのファイルドロップ」のチェックを外すと一時停止します。このON/OFFは起動中だけ有効で、次回起動はONです。「Excelドロップ設定」では画像の挿入先・形式、表示・省略を切り替える修飾キー（Shift・Ctrl・Alt）、画像とCSV・TSVそれぞれの通常時の表示・省略を保存できます。メニューの「開く」で状態画面を表示でき、×で閉じても常駐します。完全に終了するには通知領域メニューの「終了」を使います。

## CSV・TSVの展開（v0.2.2以降）

CSV・TSVの初期設定では、通常のドロップで取り込み画面が開き、Shiftを押しながらドロップすると画面を省略します。通知領域の右クリックメニューから「Excelドロップ設定」を開き、「通常ドロップ時」で画像とCSV・TSVそれぞれの表示・省略を設定して保存できます。修飾キーは画像とCSV・TSVで共通です。初期値はShiftで、Ctrl・Altにも変更できます。設定したキーを押しながらドロップすると、常に通常時と逆の動作になります。

セル上では直近に取り込みを完了した展開方式を初期値にします。初回は「指定セル」で、Excelで選択しているセルを使います。シートタブ・横スクロールバー・ステータスバー付近は「新しいシート」、リボン・数式バーなどセルを特定できない場所は「新しいブック」が初期値です。取り込み画面を表示すれば展開先を変更できます。位置で決まった初期値をそのまま使う場合、結合設定と両立する限りセル上の展開方式を引き継ぎます。

画面を省略した場合、行の除外・結合・見出しと、明示した列形式・小数桁には保存済みの設定を使います。自動判定の列は新しいデータから推定し直します。「指定セル」のブック・シート・アドレスは保存せず、ドロップしたときのExcelの選択範囲を使います。設定画面をキャンセルした場合は既定値を更新しません。

明示した列設定と新しい列構成が一致しない場合や、既存データとの衝突などで自動展開できない場合は設定画面で確認します。フォルダの場合は、省略時も先に「ファイルの絞り込み」で対象と文字コードを選びます。読込み中はキャンセルでき、画面を省略した書込みもEscで中止できます。

### 対象ファイルを選ぶ

フォルダ内を再帰検索してCSV・TSVのフルパスを一覧表示します。チェックしたファイルだけが対象です。「すべて選択／解除」は非表示分も含み、「表示分を選択／解除」は現在の検索結果だけに作用します。検索はフルパスへの部分一致、または`*`（任意文字列）・`?`（任意1文字）のワイルドカードで、大文字小文字を区別しません。入力すると一覧が更新され、隠れたファイルのチェックは保持されます。

取り込む順番は「上へ」「下へ」「パス順」で変更できます。同じフルパスのファイルは重複して取り込みません。別フォルダにある同名ファイルは別の候補として扱います。アクセスできない場所やリンクフォルダは詳細で確認してください。リンクフォルダはたどりません。取り込み画面の「対象ファイル…」からファイルを選び直せます。

「文字コード」は自動判定、UTF-8、UTF-16 LE、UTF-16 BE、Shift_JIS（CP932）から選べます。絞り込み画面では選択行のファイルへ適用し、「チェックした全ファイルに適用」をONにすると非表示分を含むチェック済みファイルへ適用します。取り込み画面では表示中のファイルへ適用し、「すべてのファイルに適用」ONまたは結合ONでは対象全体へ適用します。指定が混在する場合は「ファイル別（混在）」と表示します。変更すると再読込みし、文字コードで変わり得る列形式の手動設定は再推定します。

新しくドロップしたファイルは1件ずつ自動判定します。手動で選んだ文字コードはその取り込みだけに適用します。自動判定はBOMを優先し、BOMなしは厳密なUTF-8、次にCP932を試します。読めるが文字化けする場合は手動で指定してください。BOMなしUTF-16は手動指定が必要です。BOMと手動指定が異なる場合や、指定文字コードで読めないバイトはエラーにし、置換文字へ変換しません。最初の自動読込みで失敗した場合も、対象選択画面へ戻って文字コードを変更できます。

### 展開先と行の除外

- 「新しいブック」は1ブック内にファイル別のシート、「新しいシート」は指定ブックにファイル別のシートを作ります。
- 「指定セル」はドロップ時の選択が初期値です。隣のブック・シート・セルを変更できます。`B3:D7,F3:H7`のような複数範囲も指定でき、各左上から順に展開します。範囲の大きさでは切り詰めません。不足分は最後の表の下へ1行空けて並べます。
- 「同名のシートに追記」は拡張子を除いたファイル名と同じシートへ追加し、なければ作ります。既存表はA1を基点とし、見出しONでは1行目の列名へ対応させて並べ直します。未知の列や重複・空の見出しはエラーです。見出しは重複して書きません。追記位置は値・数式がある最終行の次で、空文字を返す数式も数えます。
- 先頭・末尾から除外する行数は各ファイルへ共通に適用します。「先頭・末尾の除外 → 空欄行の除外 → 見出し取得」の順です。引用符内の改行は1つのデータ行のままです。空欄行はすべての項目が空文字の行で、空白文字だけの値は残します。

### 結合・プレビュー・列形式

「すべてのファイルを結合」は1シートの1つの表へ縦に連結し、左端へファイル名列を加えます。ファイル選択コンボは表示せず、結合後の表を表示します。見出しONでは結合基準を「列順」「列名」から選べます。「列名」は全列を残して不足を空セルで補い、後から出た列は右に加えます。同名シートへの追記とは同時に選択できません。

プレビューは「しない」「各ファイル先頭10行」「すべて」から選べます。除外する行と見出しを取り除いたデータが対象です。プレビューが10行でも、実行時は全データを取り込みます。大容量データはディスクに保持し、画面には必要な行だけを読み込みます。設定画面はExcelより前面に表示され、最大化できます。

上段で列ごとの形式と小数桁、下段で実データを確認します。見出しクリックの並べ替えは行いません。「すべてのファイルに適用」は結合OFFの列形式・小数桁を他ファイルの同じ列番号へ適用します。

各列の「書式」に、Excelへ適用する書式コードを表示します。読み取り専用で、選択してコピーできます。形式や小数桁を変えると、下段もExcel自身で変換・書式設定した表示へ更新します。日付の表示、丸め、桁区切り、曜日、パーセント、先頭ゼロなどを確認できます。指定セル・既存の追記先は出力位置の列幅・フォント・日付方式も参照します。列幅や負の時刻などでExcelが`#####`を返す場合は、その表示と注意を示します。

プレビューのセルにマウスを置くと、元の値・書式コード・実際のセル書式・格納値・変換エラーを確認できます。「標準」等でも文字列を保持するセルの実際の書式は`@`になる場合があります。日付へ変換できない`003`などは赤いエラーセルにし、「検証結果…」で元ファイル・行・列・理由を確認できます。プレビューなし・先頭10行でも、対象全体の変換検査を行います。検査中・表示取得中・エラーがある状態では取り込めません。

書式プレビューには専用の非表示Excelを使い、出力先のブックやシートを変更しません。表示文字列と格納値を確認する機能で、WinFormsの字体の描画や、出力先にある条件付き書式・テーマ・隣接セルによる見え方すべてを複製するものではありません。書込み先の衝突・保護などは実行直前にも検査します。

数値・日付等の確認用Excelは、同じOfficeAssistの起動中は再利用し、OfficeAssistの終了時に回収します。初めて使うときは専用Excelの起動時間が加わります。書式設定方式の短い文字列だけなら起動しません。書式・値・出力属性が同じセルは表示結果を再利用し、小数桁だけの変更では全件の変換検査をやり直しません。長文の省略表示はExcel自身へ問い合わせます。

- 形式は全件から推定し、先頭ゼロ・15桁を超える番号・混在値は文字列（書式設定）を基本とします。文字列（書式設定）は出力範囲だけを`@`にし、人工的な先頭引用符を加えません。文字列（シングルクォート）も明示選択できます。数式風の文字列を数式として実行しません。
- 数値・桁区切り数値・パーセント・円の小数桁は0～15桁です。0桁は小数点を表示しません。表示だけを丸め、格納値は変更しません。
- 日付は`yyyy/mm/dd`、曜日付きは`yyyy/mm/dd (木)`、日時は`yyyy/mm/dd hh:mm:ss`、時刻は`hh:mm:ss`、経過時間は`[h]:mm:ss`です。
- CSVはカンマ、TSVはタブで区切り、引用符内の区切り文字・改行・二重引用符を保持します。UTF-8、BOM付きUTF-16、CP932に対応し、UTF-32やバイナリは対象外です。
- 対象は50ファイル、1ファイル128MiB、合計512MiB、出力合計200万セル、1セル32767文字までです。結合による不足列補完とファイル名列も数えます。Excelの行・列上限と開始位置も検査します。画像ファイルそのものとの混在ドロップは対象外です。
- 書込み前に全件の形式と衝突を検査し、既存値・数式・結合セル・テーブル等を上書きしません。エラー中もExcelのロックを維持し、設定を直して再試行できます。実行中の「中止」では今回の値と書式の取消しを試み、取消し不能ならその旨を表示します。ブックの保存はExcelで行ってください。

## 制限とエラー

- PNG/JPEG/BMP/GIF/TIFFの実ファイルを最大50件受け付けます。GIFは静止画像として挿入します。
- 1ファイル50MiB、画像100メガピクセルまでです。非画像やフォルダーを混ぜた操作は対象外です。
- 画像はワークシートのセル上にドロップしてください。
- 編集中セル、ダイアログ表示中、保護ビュー、読み取り専用ブック、保護されたシートでは挿入しません。編集を終えてから再操作してください。
- Excelの外で始めた左ドラッグが対象です。画像の実ファイルをFileDrop形式で渡し、コピーを許可するアプリから受信できます。Excel内のセル選択・図の移動を画像挿入へ置き換えません。右ドラッグ、Web上の画像、ZIP内の仮想ファイルは対象外です。
- ドロップを受理する前にOfficeAssist側で画像を確保し、挿入方法の選択中も保持します。SSCaptureが元の一時PNGを整理しても埋め込みに使えます。受信コピーは挿入完了・キャンセル・失敗時に削除し、元ファイルは変更しません。リンクされた図を使う場合は、先に通常の画像ファイルとして保存し、Explorerから渡してください。
- ExcelとOfficeAssistは同じユーザーの通常権限で実行します。管理者起動やWeb版Excelは対象外です。
- Excelの自動操作により標準の「元に戻す」履歴が失われる場合があります。挿入画像を除くにはExcel上で選択して削除してください。
- 成功結果はOfficeAssist画面で確認できます。エラーはダイアログと画面に表示されます。一括挿入の途中で失敗した場合は、今回追加した画像・数式の取り消しを試みます。取り消せなかった場合はその旨を表示します。

このバージョンではWindowsへの自動起動登録を提供していません。`--startup`を指定すると、画面を表示せずに起動できます。
