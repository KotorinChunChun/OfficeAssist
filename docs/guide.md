# 使い方

OfficeAssistとデスクトップ版Excelを起動し、エクスプローラーから画像をシートへ左ドラッグします。セル左上に画像が追加され、複数の場合は下方向に並びます。長辺は最大480ptです。画像はブックに埋め込み、元ファイルにはリンクしません。保存はExcelで行ってください。

「Excelへの画像ドロップ」のチェックを外すと一時停止します。設定は起動中だけ有効で、次回起動はONです。×で画面を閉じても常駐します。完全に終了するには画面または通知領域メニューの「終了」を使います。

## 制限とエラー

- PNG/JPEG/BMP/GIF/TIFFの実ファイルを最大50件受け付けます。GIFは静止画像として挿入します。
- 1ファイル50MiB、画像100メガピクセルまでです。非画像やフォルダーを混ぜた操作は対象外です。
- リボン・数式バー・シートタブ・グラフ専用シートへのドロップは対象外です。
- 編集中セル、ダイアログ表示中、保護ビュー、読み取り専用ブック、保護されたシートでは挿入しません。編集を終えてから再操作してください。
- エクスプローラーからの左ドラッグが対象です。右ドラッグ、Web上の画像、ZIP内の仮想ファイルは対象外です。
- ExcelとOfficeAssistは同じユーザーの通常権限で実行します。管理者起動やWeb版Excelは対象外です。
- Excelの自動操作により標準の「元に戻す」履歴が失われる場合があります。挿入画像を除くにはExcel上で選択して削除してください。
- 失敗時は通知とOfficeAssist画面の結果を確認します。一括挿入の途中で失敗した場合は、今回追加した画像の取り消しを試みます。取り消せなかった場合はその旨を表示します。

Windowsへの自動起動登録はこの版では提供しません。`--startup`による無表示起動には対応しています。
