# 使い方

OfficeAssistとデスクトップ版Excelを起動し、Excelでセル範囲を選択してから、エクスプローラーやSSCaptureの通知など、画像ファイルをドラッグできるアプリから画像をシートへ左ドラッグします。通常はダイアログを表示せず、保存済みの設定で挿入します。初期設定は選択範囲・埋め込みです。設定された修飾キー（初期値はShift）を押しながらドロップすると挿入設定を表示し、「挿入」で設定を既定として保存します。「キャンセル」では設定とシートを変更しません。ブックの保存はExcelで行ってください。

- 挿入先はドロップ位置（原寸大）、選択位置の左上（原寸大）、または選択範囲に縦横比を保って収める方法から選びます。
- 選択範囲にはExcelの範囲順に画像を１枚ずつ割り当て、挿入済みの範囲を選択から外します。画像が範囲数より多い場合は、残りすべてを最後の範囲に入れて警告します。最後の範囲に複数の図を収める場合は縦に分割し、原寸大では縦に並べます。全範囲を使い切った場合、Excelは選択を空にできないため、選択外の隣接セルへ移します。ドロップ位置では選択範囲は使用しません。
- 埋め込みは画像をブックに保存します。リンクされた図はExplorerからの画像で選べ、元ファイルへの参照を保存します。外部アプリからの画像では短命な一時ファイルへの参照切れを避けるため、リンクは選べません。
- IMAGE関数式では画像ごとに直接取得できるHTTPSの画像URLを指定します。URLは保存しないため、この形式を使うたびに設定された修飾キーを押してURLを指定します。OneDriveやSharePointの同期パスを自動変換・公開しません。認証が必要なURLやリダイレクト先の画像はExcelで表示できない場合があります。最後の範囲に複数のIMAGE関数を挿入する場合は左から右、上から下の順に空セルを使います。セルが足りない場合や既存値・結合セルがある場合は上書きせず、挿入しません。

起動すると画面を表示せず通知領域に常駐します。アイコンを右クリックし、「Excelへのファイルドロップ」のチェックを外すと一時停止します。このON/OFFは起動中だけ有効で、次回起動はONです。「Excelドロップ設定」では挿入先・形式と設定画面を呼び出す修飾キー（Shift・Ctrl・Alt）を保存できます。メニューの「開く」で状態画面を表示でき、×で閉じても常駐します。完全に終了するには通知領域メニューの「終了」を使います。

## CSV・TSVの展開

- CSVはカンマ、TSVはタブで区切ります。引用符で囲んだ項目の改行・区切り文字、二重引用符のエスケープ、空欄・空行を保持します。先頭行もデータとして取り込みます。
- UTF-8（BOM有無）、BOM付きUTF-16（LE/BE）、Shift_JIS（CP932）を判定します。BOMなしは厳密なUTF-8を優先し、読めない場合にCP932を試します。UTF-32やバイナリは対象外です。
- Excelのセルを選んでファイルをシートへドロップすると、選択範囲の左上から行列へ展開します。選択範囲の大きさでは切り詰めません。画像用の挿入先・サイズ設定と修飾キーはCSV・TSVには使用しません。
- 複数ファイルはExcelの選択範囲順に１つずつ展開します。範囲不足分は最後の展開先の下に１行空けて並べ、警告します。未使用範囲があればそれを次の選択にし、すべて使った場合は最後の表の直下へ移します。
- すべて文字列として取り込み、先頭ゼロ・長い数値・日付表記を保ちます。「=」等で始まる項目を数式として実行しません。セルの表示形式は変更しません。
- 全ファイルの解析と全展開先の検査が成功してから書き込みます。既存値・数式・結合セルがある場合、展開先同士が重なる場合、シートの行列数を超える場合は全体を中止します。書込み途中のエラーでは今回書き込んだ内容の取り消しを試みます。
- 最大50ファイル、１ファイル20MiB、合計64MiB、展開後合計20万セル、１セル32767文字までです。画像との混在には対応しません。
- OfficeAssistのファイルドロップが有効で、対応するCSV・TSVをシート上で受け取ったときに標準処理を置き換えます。一時停止中やシート外へのドロップはExcel側の処理になります。CSV・TSVの元ファイルは変更しません。

## 制限とエラー

- PNG/JPEG/BMP/GIF/TIFFの実ファイルを最大50件受け付けます。GIFは静止画像として挿入します。
- 1ファイル50MiB、画像100メガピクセルまでです。非画像やフォルダーを混ぜた操作は対象外です。
- リボン・数式バー・シートタブ・グラフ専用シートへのドロップは対象外です。
- 編集中セル、ダイアログ表示中、保護ビュー、読み取り専用ブック、保護されたシートでは挿入しません。編集を終えてから再操作してください。
- Excelの外で始めた左ドラッグが対象です。画像の実ファイルをFileDrop形式で渡し、コピーを許可するアプリから受信できます。Excel内のセル選択・図の移動を画像挿入へ置き換えません。右ドラッグ、Web上の画像、ZIP内の仮想ファイルは対象外です。
- ドロップを受理する前にOfficeAssist側で画像を確保し、挿入方法の選択中も保持します。SSCaptureが元の一時PNGを整理しても埋め込みに使えます。受信コピーは挿入完了・キャンセル・失敗時に削除し、元ファイルは変更しません。リンクされた図を使う場合は、先に通常の画像ファイルとして保存し、Explorerから渡してください。
- ExcelとOfficeAssistは同じユーザーの通常権限で実行します。管理者起動やWeb版Excelは対象外です。
- Excelの自動操作により標準の「元に戻す」履歴が失われる場合があります。挿入画像を除くにはExcel上で選択して削除してください。
- 成功結果はOfficeAssist画面で確認できます。エラーはダイアログと画面に表示されます。一括挿入の途中で失敗した場合は、今回追加した画像・数式の取り消しを試みます。取り消せなかった場合はその旨を表示します。

Windowsへの自動起動登録はこの版では提供しません。`--startup`による無表示起動には対応しています。
