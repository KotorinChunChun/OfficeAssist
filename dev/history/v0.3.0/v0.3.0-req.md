# OfficeAssist v0.3.0 要求案

他バージョンの実装中は本書を読まず、要求を取り込まないこと。

作成日: 2026-11-06。対象版の番号は設計整理用の仮置き。利用者からは今回、設計書の作成と追加機能の再検討を依頼されている。製品実装・導入版の更新・公開は未着手。

## 利用者から指定された要求

| ID | 要求 |
| --- | --- |
| R01 | 警告・表示メッセージのセルアドレスから絶対参照の`$`を除く。 |
| R02 | 展開先の「選択中のセル」を「指定セル」に変更する。隣にブック名・シート名・セルアドレスを表示し、初期値は選択中のセルとする。プルダウンまたはテキストボックスで変更できるようにする。 |
| R03 | 各ファイルの先頭から除外する行数、末尾から除外する行数、空欄行を除外するオプションを追加する。 |
| R04 | 「すべてのファイルを結合」を追加する。ONでは1シートへ縦に連結し、ファイル選択をなくす。左端へファイル名列を追加し、プレビューには結合後のデータを表示する。 |
| R05 | データのプレビューを「しない」「各ファイル先頭10行」「すべて」から選べるようにし、重いファイルにも対応する。 |
| R06 | 結合と「先頭行を見出しとして扱う」が両方ONの場合、結合基準を「列順」「列名」から選べるようにする。 |
| R07 | 以上を踏まえた設計書を作り、追加で必要な機能を再検討する。 |

## 設計上の提案・未確定事項

行の数え方と除外順序、列名の照合方法、列不足・重複見出し、初期設定、大容量の上限、複数選択範囲との関係は利用者から個別指定されていない。[設計書](v0.3.0-imp.md)に推奨案と判断理由を記す。これらの提案を承認済み要求と混同しない。

追加候補は、ファイル順の変更、進捗・キャンセル、取り込み前の全件検査、型推定の範囲表示、エラーの元ファイル・行への対応、設定保存、文字コード・区切り文字の指定を再検討する。

## 維持する既存機能

- 列単位の形式・小数桁、文字列の書式設定方式、先頭ゼロ・長い番号・数式風文字列の保持。
- 上段の横並び列設定と下段の実データ、見出しクリックの並べ替え禁止、最大化。
- Excelより前面の取り込み画面とエラー表示、エラー中のExcel操作ロック、設定変更後の再試行。
- 既存データ・数式・結合セル・保護・シート端・展開先同士の重なりの検査。
- 結合OFF時の複数ファイルと複数選択範囲への順次展開、使用済み選択範囲の除外。
- 画像ドロップ、通知領域への常駐、既存の管理・起動契約。
