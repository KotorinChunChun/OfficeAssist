# OfficeAssist v0.2.1

Windows 11 x64向け開発版です。セットアップとZIPに.NETランタイムを同梱しています。

- SSCaptureなど、Explorer以外のアプリからも画像をExcelへドロップできます。受信時に画像を確保し、送信元の一時ファイルが削除されても挿入できます。
- 画像は選択範囲へ先頭から順に挿入し、使用済み範囲を選択から外します。範囲が足りない場合は最後の範囲へ残りを挿入して警告します。
- 通知領域のメニューから画像の挿入先・形式・設定画面を開く修飾キーを変更できます。ウィンドウを閉じても常駐を継続します。
- CSV・TSVのドロップを独自の取り込みへ置き換えます。新しいブック・新しいシート・選択中のセルを選び、既存データとの衝突を検査します。
- ファイル選択、すべてのファイルへの適用、横並びの列設定、実データ表示、最大化に対応します。
- 列形式は自動推定し、文字列（書式設定／シングルクォート）・標準・数値・桁区切り・パーセント・円・日付・曜日付き日付・日時・時刻・経過時間から変更できます。数値系の小数桁は0～15桁で設定でき、0桁では小数点を表示しません。
- エラーは取り込み画面の前面に表示し、Excelの操作ロックを維持したまま設定変更と再試行ができます。

CLI検証145件、専用の非表示Excelでの値・書式・ロック検証が成功しています。GUI操作は利用者が確認済みです。

CSV・TSVは１回20万セルまで、画像との混在は対象外です。IMAGE関数には認証なしで直接取得できるHTTPS画像URLが必要です。ハッシュ照合はコード署名による発行元保証ではありません。

インストールにはsetup.exeを使用してください。ZIPは展開して利用できる実行用配布物です。SHA256SUMS.txtでファイルを照合できます。KotorinToys向けの配布台帳も同梱します。
