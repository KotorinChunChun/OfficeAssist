# v0.1.0 要求

2026-10-27。依頼：Officeソフトの動作を自動化する補助常駐ソフトを新設し、最初の機能としてフォルダーからExcel画面への画像ドロップによる挿入を実装する。

## 未実装

なし。

## 実装済

- R1：単体起動できる常駐アプリOfficeAssistを独立Gitで作成する。2026-10-28の追加指示により通常起動・`--startup`とも無表示でタスクトレイへ常駐し、二重起動でも画面を開かない。自動起動の新規登録はしない。
- R2：エクスプローラーからExcelシートへの画像ファイルのドロップを受け、対象ウィンドウ・シートのセル位置に埋め込む。複数画像は縦配置。元ファイル・クリップボードを変更しない。
- R3：機能のON/OFF、通知領域からの表示・終了、挿入結果と失敗理由を提供する。非画像、編集できないシート、キャンセルで誤挿入しない。
- R4：自動検証と実Excelでの動作確認を行い、操作方法と制限を記録する。

## 実装上の選択

- 対象はWindows 11とデスクトップ版Excel。画像はPNG/JPEG/BMP/GIF/TIFF、1回50件まで。
- セル内画像ではなく浮動画像。縦横比を保ち、長辺480ptを上限に縮小する。
- 配布・インストール・GitHub公開は今回の対象外。

## 受入確認

利用者が試験フォルダーからExcelへ画像をドロップし、2026-10-27に「挿入されました」と回答。自動COM検証・管理連携・未確認範囲は実装報告を参照。
